多套自动化 BI 看板从 0 到 1 落地

联想天猫官旗 · 2026.05–至今

业务痛点：直播、万相台、淘客、达播等渠道数据分散，业务方每天花大量时间拼表、对口径，决策缺乏统一视图。

我的动作：基于 Quick BI + SQL 从 0 到 1 搭建全店驾驶舱、大曝光、淘客 CPS、直播、万相台等 6+ 套看板，统一 6 大业务板块口径，累计处理近 150w 条数据。

量化结果：数据分析时长从 1h 左右压缩至 5min；看板成为大促盯盘、周报复盘的统一事实基础，并复用至京东官旗与其他业务线。

618 大曝光素材 A/B 赛马

联想天猫官旗 · 2026.05–06

业务背景：618 大曝光项目 180w 预算，多渠道多品类并行，素材效果难判断、点击率低损耗预算。

测试设计：围绕背景色、文案内容、创意场景、赠品展示、引导按钮、产品角度等维度，开展两轮 A/B 赛马，覆盖 200+ 素材。

核心结果：整体 CTR 提升至 5.76%，同比提升 50%+；沉淀高点击素材特征与 SOP，复用至暑期大促，部分资源位点击率高于行业大盘约 1pct。

AI 插件：人群画像数据提取助手

联想天猫官旗 · 2026

痛点：品牌数据银行人群画像分析是高频任务，但取数、整理、命名、出报告操作重复繁琐，单次耗时约 1h。

方案：用 CodeBuddy / Codex 把流程工具化，开发浏览器插件：自动提取画像数据 → 智能命名 → 调用大模型 API 按模板生成 HTML 报告。

结果：人群分析耗时从 1h 压缩至 2min，效率提升 90%+；插件已推广至团队 50+ 人使用，沉淀为可复用的工具化落地方法。
